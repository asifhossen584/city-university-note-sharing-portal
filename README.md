# City University — Notes Sharing Portal

A University Notes Sharing Portal for City University Bangladesh. Students
upload, search, preview, download, rate, comment on and bookmark study notes;
admins approve uploads and manage users, courses and notices.

## What is in this repository

| Folder | What it is |
|---|---|
| `backend-mysql/` | Node.js + Express + MySQL backend API (the server) |
| `react-frontend-connected/` | React frontend that calls the backend API (the website) |

The course catalogue has 294 courses, taken from the university's official
site (cityuniversity.ac.bd). No courses are invented.

## Run it (on your own PC)

### 1. Start MySQL

Make sure MySQL/MariaDB is running and the `notes_portal` database exists.
The backend README explains the one-time setup and seed.

### 2. Start the backend

```bash
cd backend-mysql
npm install        # first time only
npm run seed       # first time only (creates the admin + the 294 courses)
npm start          # runs on http://localhost:3000
```

Leave that window running. The backend must be up while you use the site.

### 3. Serve the frontend

Open the `react-frontend-connected` folder in VS Code and use **Live Server**
(right-click `index.html` → "Open with Live Server"), or from a terminal
inside that folder run `npm start`. Then open `http://localhost:5500`.

Do not open `index.html` directly from the file system (`file://`) — the
browser blocks the API calls that way.

### 4. Log in

Default logins are listed in `backend-mysql/README.md` (admin
`admin@city.edu` / `Admin@123` — change that password after the first login).
New registrations stay inactive until an admin approves them.

## Notes

- The frontend's four Home-page photos (`react-frontend-connected/public/assets/`)
  are uploaded separately through the GitHub web interface (binary files).
- The backend's sample PDFs in `backend-mysql/uploads/` are generated by the
  seed script and are not stored here.
- Login is checked server-side; passwords are stored only as bcrypt hashes in
  MySQL. No credential appears in any file the browser can load.
